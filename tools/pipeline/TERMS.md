# Terms

`terms.json` เก็บชื่อเฉพาะภาษาญี่ปุ่นคู่กับชื่อภาษาอังกฤษทางการ (`{"アルフィノ": "Alphinaud"}`) คำแปลภาษาไทยใช้ชื่อภาษาอังกฤษนั้นตามตัวอักษร ไม่ทับศัพท์และไม่แปล

## หลักการใช้

- pipeline ค้นชื่อในภาษาญี่ปุ่นของแต่ละบรรทัด แล้วส่งให้ Haiku เฉพาะชื่อที่บรรทัดนั้นใช้ ในช่อง `terms` ของบรรทัด
- ค้นจากชื่อที่ยาวที่สุดก่อน และชื่อที่จับได้จะไม่ซ้อนกัน บรรทัดที่มี エーテライト・プラザ จึงได้ชื่อนั้นชื่อเดียว ไม่ได้ エーテライト ที่อยู่ข้างในด้วย
- ชื่อที่มีเฉพาะในภาษาอังกฤษ เช่นคนที่ถูกเรียกใน "Master Alphinaud, ..." ต้องอยู่ในคำแปลด้วย ส่วนคำนำหน้าชื่อให้แปลเป็นไทย (ท่าน Alphinaud)
- lint `name` ตรวจว่าคำแปลมีชื่อภาษาอังกฤษของทุกชื่อที่ส่งไป ส่วน lint `script` ยอมให้มีตัวอักษรละตินเฉพาะคำที่อยู่ในภาษาอังกฤษของบรรทัดหรือใน `terms.json`

## ทำไมใช้ภาษาอังกฤษ

- เกมต้องตั้งเป็นภาษาอังกฤษ เพราะ plugin สร้าง key จาก `text_en` ป้ายชื่อตัวละคร แผนที่ และ journal จึงเป็นภาษาอังกฤษ ชื่อในบทพูดจึงควรตรงกับที่ผู้เล่นเห็น
- กฎ "อ่านเสียงญี่ปุ่น" ใช้ได้กับคาตาคานะเท่านั้น แต่ยังมีชื่อคันจิอีกมาก เช่น 暁の血盟, 蛮神, 黙約の塔, 剣術士 รวมถึงสถานที่ใน `PlaceName` ราว 742 แถวที่มีคันจิ ถ้าอ่านตามเสียง 暁の血盟 จะกลายเป็น "อาคัตสึกิ โนะ เคตสึเม" ซึ่งคนไทยอ่านแล้วไม่เข้าใจ ใช้ภาษาอังกฤษแล้วคันจิกับคาตาคานะใช้กฎเดียวกันได้

## สร้างไฟล์

```
tools/pipeline/.venv/bin/python tools/pipeline/build_terms.py
```

ไม่เรียก model อ่านจาก submodule `tools/pipeline/dl/ffxiv-datamining` (เลือก commit ด้วย `--at`) ชื่อจาก sheet จะเป็น term เมื่อผ่านทุกข้อต่อไปนี้

- ภาษาอังกฤษขึ้นต้นด้วยตัวพิมพ์ใหญ่ sheet เขียนคำนามทั่วไปเป็นตัวพิมพ์เล็ก เช่น vulture, delivery moogle จึงถูกตัดออก `ClassJob` และ `Mount` เป็นตัวพิมพ์เล็กทั้งหมด จึงไม่ได้ใช้
- ถ้าชื่อเดียวกันมีหลายแบบในภาษาอังกฤษ ใช้แบบที่สั้นที่สุดเมื่อแบบอื่นมีคำนั้นอยู่ทั้งหมด เช่น Gaius ใน Gaius van Baelsar ถ้าไม่เป็นแบบนั้นจะไม่ใช้ชื่อนั้น เช่น エーテライト・プラザ มีแค่ Ul'dah Aetheryte Plaza และ Kugane Aetheryte Plaza ให้ Haiku อ่านจากภาษาอังกฤษของบรรทัดแทน
- ภาษาญี่ปุ่นปรากฏในไฟล์เควสต์ main scenario หรือไฟล์ `cut_scene`
- ตัด "the" ที่นำหน้าออก และตัดหมวดหมู่ที่นำหน้าชื่อ duty ออก (`外郭攻略 カストルム・メリディアヌム` เหลือ `カストルム・メリディアヌム`)

| sheet | term (datamining `52a72b38aa2f`) | หมายเหตุ |
|---|---|---|
| `ENpcResident` | 1040 | ตัวละคร |
| `BNpcName` | 153 | ศัตรูที่มีชื่อ |
| `PlaceName` | 1086 | สถานที่ |
| `ContentFinderCondition` | 17 | ชื่อ duty |
| `Race`, `Tribe` | 8, 12 | |
| `Town` | 0 | ทุกชื่ออยู่ใน `PlaceName` แล้ว |
| `terms_manual.json` | 2 | ชื่อที่ไม่มีใน sheet ใดเลย เช่น 暁 → Scions เขียนด้วยมือ และใช้แทนชื่อจาก sheet |

ถ้าชื่อภาษาญี่ปุ่นเดียวกันอยู่หลาย sheet ใช้ sheet ที่อยู่บนกว่าในตาราง
